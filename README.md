# Twin Technologies website (v5)

Static multi-page site for Twin Technologies. Deployed on Netlify with a Progressive Web App manifest/service worker.

## What changed in this round
- **Repositioned**: Language Services and Services are now co-equal, prominent header tabs. Academy is deliberately de-emphasized — removed from the header/hero entirely, folded into the hamburger "More" menu (with Curriculum nested under it), and given one quiet text mention near the bottom of the homepage. Its own pages, curriculum and structure are untouched — just not pushed at first glance.
- **Private Lessons promoted**: the Hausa/Fulfulde/Pidgin private-lessons page is now a full marquee banner on the homepage (and fixed a real contrast bug — white text was sitting on a near-white pill).
- **Removed a redundant homepage section** ("One company, two ways to move forward") that was duplicating the newer Language Services/Services section right below it.
- **Real content folded in permanently** (previously a bolt-on stylesheet limited to 4 pages, now baked into every page): real social links, the "Meet Your Instructors" section on About (with Aliyu Musa's bio, corrected to note his 5 years and language-services specialty), the real categorized gallery photos.
- **Credentials refreshed**: Cypherlanguages updated to 200+ hours, Tamashek and Zarma added as named language pairs with a catch-all note for other African languages, CAT tools (Smartcat/Phrase/Trados/MemoQ/XTM/Wordfast) and Proz.com membership added, and real animated stat counters (12+ years, 400,000+ words, 28,000,000+ words reviewed, 200+ hours) added to the Language Services page — these existed in code from the last round but were never actually placed on a page.
- **New portfolio section on Services**: Learning Roots Royal Academy (described, no live link given the ongoing domain dispute), plus placeholder cards for Babakasa Global Investment and Hoina Charity Foundation — **replace these two with real screenshots/links**, they're currently text-only placeholders since no link was provided yet.
- **No payment/account details anywhere** — Academy and Services both end in a plain request form; all pricing and payment happens off-site afterward, privately.
- Bindir Knowledge Center: zero mentions anywhere, per instruction.

## Deploy
Upload the contents of this folder to the GitHub repository connected to Netlify (mobile web UI → "Add file → Create new file", full folder paths). Netlify auto-deploys the root directory.
